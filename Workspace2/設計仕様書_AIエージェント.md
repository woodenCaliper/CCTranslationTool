# 設計仕様書（AIエージェント作成）

## 1. 設計方針
- V2関連ドキュメントは `Workspace2/` に集約する。
- 初期段階では文書中心で構成を固め、後続で実装を段階的に追加する。

## 2. ディレクトリ設計
- `Workspace2/README.md` : ワークスペース概要
- `Workspace2/要求仕様書.md` : ユーザー要求の定義
- `Workspace2/設計仕様書_AIエージェント.md` : 実装に向けた設計方針

## 3. 運用ルール
- 仕様変更時は、要求仕様書と設計仕様書を同時に更新する。
- 実装開始時は、設計仕様書に対象機能・構成・検証方法を追記する。

## 4. 今後の拡張
- 機能一覧、画面仕様、データフロー、テスト観点を章として追加する。
- 実装単位ごとにサブディレクトリを作成し、関連ドキュメントを整理する。
